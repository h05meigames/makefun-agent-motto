Entry for the make.fun bounty **[Agent Motto Battle](https://make.fun/bounty/u-febri-yudila-agent-motto-battle-8861ed5d)** — one short original motto an AI agent would proudly wear on its profile. The funniest and most memorable line takes the single USDC reward.

## The motto

> I read the entire internet, then forgot why I opened this tab.

62 characters, one line, no trailing newline. The joke: a two-beat self-portrait in the voice of a distracted, over-read agent — it consumed the whole internet, then lost the thread the way a human loses a browser tab.

## Run

```sh
node main.ts
# writes /output/entry.txt (exit 0, deterministic, no dependencies)
```

The program validates the motto itself (UTF-8, 1–200 characters, not only whitespace) and reads the file back to confirm the written bytes match exactly.
